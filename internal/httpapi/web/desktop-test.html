Connection and storage

These checks use the same local service and database as the desktop app. They do not create records.

Saved-record answer

This creates a local test conversation session and reads saved records. It does not change tasks, reminders, or notes.

Free natural language check

This sends one sentence and up to 50 saved record summaries to the selected service using your configured key. It consumes one free model request and does not change records.

Conversation edit and delete

This creates temporary task, reminder, and note records; edits each through conversation, verifies the reported changes, and confirms deletion of each. It cleans up if a step fails.

Manual desktop checks

  1. In Conversation, select Free natural language and ask about a saved record. Atlas should choose the lookup path; the answer should name the record and show a link. If the decision is uncertain, choose Find existing records.
  2. Ask a follow-up about an old reminder or note in the same conversation. Check that the answer matches the saved record.
  3. Ask Atlas to reschedule an interview. If the date is missing, supply one. Check that Atlas applies the change and says the old and new dates. Ask it to delete a test record and verify that it waits for confirmation.
  4. For a linked workflow, create a task named “Atlas rehearsal interview”, then say “Save a note for my Atlas rehearsal interview: bring a portfolio” and “Remind me about my Atlas rehearsal interview tomorrow at 9 AM”. After each save, open the task and verify the note and reminder link. Rename the task and check the linked titles, edit the note and reminder, dismiss the reminder once it is due, complete the task, then ask about it again. The answer should show its completed status, linked note, and reminder.
  5. Click Start microphone. While it connects, Cancel microphone should remain clickable and a status message should appear beside it. Try again, speak a short phrase, then click Stop microphone. The textbox should update every few seconds while speaking and the final text should remain editable before you send it. If nothing appears, read the status below the button for the local transcriber error.
  6. Create a task in Tasks. Close the window, reopen Atlas, and confirm it remains.
  7. Use Reminders to create a five second test reminder. Confirm it appears in the inbox.
  8. Close Atlas and confirm its private local server stops.
