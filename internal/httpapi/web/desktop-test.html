Continuous conversation check

Use Conversation in Jev mode. Create a task with a note and an explicit reminder, then ask about it in the same conversation. Reschedule it, dismiss the reminder, complete the task, and ask about it again. The reply box should stay available after saving, and each edit should name what changed.

Try “I need to prepare for my interview by tomorrow at 6pm, note that I should bring my portfolio and remind me tomorrow at 5pm”. The task, linked note, and linked reminder should save together. Then ask “When is my interview?”

Ambiguous follow-up workbench

Exercise one mixed-workflow conversation a turn at a time. Start with a saved-record question, then try short follow-ups such as “move it to Friday”, “what did I write down for that?”, “the reminder instead”, or “back to the grocery list”. The trace shows the recent record and ranked context Atlas supplied to orchestration. Each send uses the configured Jev flow.

Manual desktop checks

  1. In Conversation, select Jev and ask about a saved record. The answer should name the record and show a link. If the decision is uncertain, choose Find existing records.
  2. Ask a follow-up about an old reminder or note in the same conversation. Check that the answer matches the saved record.
  3. Ask Atlas to reschedule an interview. If the date is missing, supply one. Check that Atlas applies the change and says the old and new dates. Ask it to delete a test record and verify that it waits for confirmation.
  4. For a linked workflow, create a task named “Atlas rehearsal interview” with a deadline, then say “Save a note for my Atlas rehearsal interview: bring a portfolio” and “Remind me about my Atlas rehearsal interview one hour before”. Move the reminder two hours later and verify that Atlas moves the task deadline and any other active, non-repeating linked reminders by two hours in the same response. Move the task deadline and verify the reminders preserve their offsets. Rename the task and check the linked titles, edit the note, dismiss the reminder once it is due, complete the task, then ask about it again. The answer should show its completed status, linked note, and reminder.
  5. In Jev mode, try a follow-up such as “I meant a reminder” when Atlas asks which action to take. If asked about an optional note, “I don’t need one” should skip it.
  6. In Jev mode, start “I need to drop mummy tomorrow morning”. Atlas should not invent a 9am notification. If you want to track leaving separately, say so before confirming the drop-off task and inspect the proposed change.
  7. Click Start microphone. While it connects, Cancel microphone should remain clickable and a status message should appear beside it. Try again, speak a short phrase, then click Stop microphone. The textbox should update every few seconds while speaking and the final text should remain editable before you send it. If nothing appears, read the status below the button for the local transcriber error.
  8. Create a task in Tasks. Close the window, reopen Atlas, and confirm it remains.
  9. Use Reminders to create a five second test reminder. Confirm it appears in the inbox.
  10. Close Atlas and confirm its private local server stops.
