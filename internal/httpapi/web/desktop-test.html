Connection and storage

These checks use the same local service and database as the desktop app. They do not create records.

Ready.

Manual desktop checks

  1. In Conversation, click Start microphone. While it connects, Cancel microphone should remain clickable and a status message should appear beside it. Try again, speak a short phrase, then click Stop microphone. A partial transcript should appear while recording and the final text should remain editable before you send it.
  2. Create a task in Tasks. Close the window, reopen Atlas, and confirm it remains.
  3. Use Reminders to create a five second test reminder. Confirm it appears in the inbox.
  4. Close Atlas and confirm its private local server stops.
