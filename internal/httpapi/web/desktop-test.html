Manual desktop checks

  1. In Conversation, select Jev via OpenRouter and ask about a saved record. Jev should choose the lookup path; the answer should name the record and show a link. If the decision is uncertain, choose Find existing records.
  2. Ask a follow-up about an old reminder or note in the same conversation. Check that the answer matches the saved record.
  3. Click Start microphone. While it connects, Cancel microphone should remain clickable and a status message should appear beside it. Try again, speak a short phrase, then click Stop microphone. A partial transcript should appear while recording and the final text should remain editable before you send it.
  4. Create a task in Tasks. Close the window, reopen Atlas, and confirm it remains.
  5. Use Reminders to create a five second test reminder. Confirm it appears in the inbox.
  6. Close Atlas and confirm its private local server stops.
