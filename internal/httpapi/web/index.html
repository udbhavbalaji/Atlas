      06 / CONTRACTS

      API lab

      Inspect structured responses, validation, and safe retries.

      What you can test
      • Create a record, then Replay last request to verify creation deduplication.
      • Change the input while keeping the key to inspect a conflict.
      • Read task, reminder, or note state with linked records.
      • Send malformed JSON to inspect structured errors.

      Inspect structured state and try retries. Requests here use your real Atlas data.

      For creation, send again with the same key and body to get the original record. Change the body without changing the key to see a conflict. A new key creates a new record.

      API response schemas (OpenAPI)

      Actions in other tabs also show their latest structured response here.
