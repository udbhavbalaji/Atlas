# Atlas for macOS

The macOS preview is a native AppKit window with WKWebView. It opens the same conversation-first interface as the Omarchy app and runs the Go Atlas service only while the window is open. Records and optional `groq.key` or `openrouter.key` files live in `~/Library/Application Support/Atlas/`.

On a Mac with Xcode command line tools and Go 1.27 or newer, run `desktop/macos/setup-transcription.sh` once, then `desktop/macos/build.sh` and `open dist/macos/Atlas.app`. The setup installs Homebrew's `whisper.cpp` and its English `base.en` model (about 142 MiB) locally. Atlas finds `whisper-cli` in either standard Homebrew location when launched from Finder. `ATLAS_WHISPER_CLI` and `ATLAS_WHISPER_MODEL` can override those paths. The build script signs the local bundle with an ad hoc signature. It is not notarized or packaged for distribution.

The build script copies `data/groq.key` and `data/openrouter.key` into `~/Library/Application Support/Atlas/` only when the corresponding desktop key does not already exist. You can place a Groq key in `~/Library/Application Support/Atlas/groq.key` yourself with mode 600. With Atlas closed and Python 3 available, the script imports `data/atlas.db` only when the macOS database has no tasks, reminders, or notes; it keeps a `.before-import` backup and does not overwrite a populated profile. Records are local to each computer until you move or sync them yourself.

Open **Desktop checks** from the conversation screen to test service, storage, saved-record lookup, edits, deletion, and audio capabilities. With a Groq key, **Free natural language · Groq** uses `openai/gpt-oss-120b` to turn a sentence into an action and fields. Groq documents a free tier with 1,000 requests per day for this model. OpenRouter free and Jev remain separate choices; OpenRouter free capacity can be rate limited. The selected model receives the sentence and up to 50 saved record summaries. Ask `When is my interview?` to get the saved due time and record link; follow-up questions can retrieve old reminders or note text. Ask to reschedule an interview and Atlas will ask for a date if needed, apply the edit, and report the old and new values. Deletion names the exact record and requires confirmation. In Conversation, click **Start microphone** to stream PCM audio to the local Atlas service. It sends provisional transcripts starting around two seconds and then every few seconds while you speak, followed by a final transcript when you stop (30 second limit). Review or edit the text before sending. Atlas discards the audio after transcription, including its temporary WAV file. Typed turns use the same durable conversation path. Reminders currently surface in the in-app inbox, not as macOS notifications.

The Go server can be cross-compiled on Linux, but this native shell must be compiled and run on a Mac. The app grants the local Atlas page WebKit microphone access; macOS still asks for system microphone permission. macOS window behavior and live microphone capture need verification on a Mac.
