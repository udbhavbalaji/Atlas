# Atlas for macOS

The macOS preview is a native AppKit window with WKWebView. It opens the same conversation-first interface as the Omarchy app and runs the Go Atlas service on `127.0.0.1:8080` only while the window is open. The stable address keeps local conversation recovery and iPhone Simulator connections working across app restarts. If another process uses port 8080, close it or configure a shared server URL. Records and optional `groq.key` or `openrouter.key` files live in `~/Library/Application Support/Atlas/`.

On a Mac with Xcode command line tools and Go 1.27 or newer, run `desktop/macos/setup-transcription.sh` once, then `desktop/macos/build.sh` and `open dist/macos/Atlas.app`. The setup installs Homebrew's `whisper.cpp` and its English `base.en` model (about 142 MiB) locally. Atlas finds `whisper-cli` in either standard Homebrew location when launched from Finder. `ATLAS_WHISPER_CLI` and `ATLAS_WHISPER_MODEL` can override those paths. The build script signs the local bundle with an ad hoc signature. It is not notarized or packaged for distribution.

The build script copies `data/groq.key` and `data/openrouter.key` into `~/Library/Application Support/Atlas/` only when the corresponding desktop key does not already exist. You can place a Groq key in `~/Library/Application Support/Atlas/groq.key` yourself with mode 600. With Atlas closed and Python 3 available, the script imports `data/atlas.db` only when the macOS database has no tasks, reminders, or notes; it keeps a `.before-import` backup and does not overwrite a populated profile. In default mode, records stay in that local database.

To share records with the browser, Omarchy, and iPhone, set `ATLAS_SERVER_URL=https://your-private-atlas-address` when launching, or put that root URL in `~/Library/Application Support/Atlas/server-url` (one line). The app then connects to that Atlas backend without starting the bundled local server or writing its local SQLite database. A loopback HTTP URL is accepted for local testing. If the configured server is unavailable, Atlas shows an error instead of opening a different database. Existing local records are not uploaded or merged. Use `/sync-test` on the shared backend to check its address and counts. Conversation reports go by HTTP to the shared server's `/api/v1/debug/reports` route.

Open **Desktop checks** from the conversation screen to test service, storage, saved-record lookup, edits, deletion, and audio capabilities. With a Groq key, **Free natural language · Groq** uses `openai/gpt-oss-120b` to turn a sentence into an action and fields. Groq documents a free tier with 1,000 requests per day for this model. OpenRouter free and Jev remain separate choices; OpenRouter free capacity can be rate limited. The selected model receives the sentence and up to 50 saved record summaries. Ask `When is my interview?` to get the saved due time and record link; follow-up questions can retrieve old reminders or note text. Ask to reschedule an interview and Atlas will ask for a date if needed, apply the edit, and report the old and new values. Deletion names the exact record and requires confirmation. In Conversation, click **Start microphone** to stream PCM audio to the local Atlas service. It sends provisional transcripts starting around two seconds and then every few seconds while you speak, followed by a final transcript when you stop (30 second limit). Review or edit the text before sending. Atlas discards the audio after transcription, including its temporary WAV file. Typed turns use the same durable conversation path. Reminders currently surface in the in-app inbox, not as macOS notifications.

The Go server can be cross-compiled on Linux, but this native shell must be compiled and run on a Mac. The app grants the local Atlas page WebKit microphone access; macOS still asks for system microphone permission. A connected audio input device is required; a Mac mini with only speakers cannot record, and its iPhone Simulator may report the same missing input. Live speech capture still needs verification with a connected microphone.

The current microphone streaming endpoint accepts local clients only, so in shared server mode type or use system dictation. The routing keys and audio backend on the shared service determine its available capabilities.

When the connected backend has an OpenRouter key, final Jev, free, and Groq list answers may use one writing request to `qwen/qwen3.8-27b:free` for a short introduction. Atlas accepts only a vetted introduction and appends the verified list items unchanged. Other final answers use Atlas's verified wording without a writing request. An unavailable or rejected list introduction leaves the verified result visible with a warning. This uses the backend's key, including when the Mac connects to Apex. Open `/response-test` on that backend to try fixture replies without a model call or record change.
