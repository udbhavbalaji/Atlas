# Atlas for Omarchy

The Linux desktop app opens a conversation-first Atlas interface in a GTK 3 and WebKitGTK 4.1 window. By default, it starts a private loopback Go server on an available port and stops it when the window closes. Records are stored in `${XDG_DATA_HOME:-~/.local/share}/atlas/atlas.db`; an optional OpenRouter key can be placed in `${XDG_CONFIG_HOME:-~/.config}/atlas/openrouter.key` or supplied via `OPENROUTER_API_KEY`.

To use the same records as the web and iPhone apps, configure a private HTTPS Atlas server address. Set `ATLAS_SERVER_URL=https://your-private-atlas-address` when launching, or put that root URL in `${XDG_CONFIG_HOME:-~/.config}/atlas/server-url` (one line). The desktop window then connects to that backend and does not start a local server or write its own SQLite database. A loopback HTTP URL is accepted for local testing. If the configured server is unavailable, Atlas shows an error rather than using an unrelated local database. Existing local records are not uploaded or merged. Open `/sync-test` on the shared backend to check its address and counts.

This was built against Omarchy 4.0.1 on x86_64 Wayland/Hyprland. GTK 3, WebKitGTK 4.1, their development headers, Go 1.27, and `pkg-config` are required to build. The installed app requires the GTK/WebKit runtime libraries, PulseAudio-compatible `parec` (provided by the local PipeWire/PulseAudio stack), and Voxtype for direct microphone capture and transcription. WebKit capture remains a fallback when `parec` is unavailable.

Run `desktop/linux/build.sh` and then `dist/linux/atlas-desktop`, or run `desktop/linux/install.sh` to place the app in the user's local application directory and add it to the launcher. The installer copies an existing `data/openrouter.key` into the desktop config only when no desktop key exists. With Atlas closed, it imports `data/atlas.db` only when the desktop database has no tasks, reminders, or notes, keeps a `.before-import` backup, and never overwrites a populated desktop profile. No Omarchy configuration changes are needed.

The native window starts on the conversation screen. With a Groq key in `${XDG_CONFIG_HOME:-~/.config}/atlas/groq.key` (or `GROQ_API_KEY`), **Free natural language · Groq** uses `openai/gpt-oss-120b` to turn a sentence into an action and fields. Groq documents a free tier with 1,000 requests per day for this model. OpenRouter free and Jev remain separate choices; OpenRouter free capacity can be rate limited. The selected model receives the sentence and up to 50 saved record summaries. Ask `When is my interview?` to get the saved due time and a record link; follow-up questions can retrieve old reminders or note text. Ask to reschedule an interview and Atlas will ask for a date if needed, apply the edit, and report the old and new values. Deletion names the exact record and requires confirmation. Use **Records and tests** to open the full browser interface, or **Desktop checks** to inspect a model plan without changing records. Click **Start microphone** to capture PCM from the default microphone directly in the local Atlas service, without relying on WebKit microphone permissions. Voxtype provides provisional transcripts starting around two seconds and then every few seconds while you speak, followed by a final transcript when you stop (30 second limit). Review or edit the text before sending. Atlas discards the audio after transcription, including its temporary WAV file. If Voxtype fails, the status shows its local error. Reminders currently appear in the in-app inbox, not as OS notifications.

With a shared backend, Atlas's current microphone streaming is unavailable because its transcription endpoint accepts local clients only. Type or use system dictation in that mode. The model keys and audio backend on the shared server determine its available routing and transcription capabilities. Conversation reports go by HTTP to the shared server's `/api/v1/debug/reports` route.

The shared conversation page gives short spoken summaries for lists of tasks, reminders, and notes while keeping full details on screen. **Stop speaking** or Escape interrupts playback. Open `/speech-test` on the configured server to check this with fixtures, without a model call or record change. An Omarchy window connected to Apex receives these web changes when the Apex service is updated; no separate frontend copy lives in the native launcher.

In Jev mode, natural-language corrections to a pending task or reminder draft trigger one additional Jev decision about which time field to change. Atlas parses the new time locally and shows the revised proposal. If the new task deadline precedes an earlier guessed reminder, Atlas removes that reminder and says so before saving.
